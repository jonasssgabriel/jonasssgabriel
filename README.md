## Projetos

**[RegEx Elite](https://github.com/jonasssgabriel/ConjuntosRegularesSystem)**
Aplicação web didática e interativa sobre linguagens regulares e expressões regulares, feita em grupo para a disciplina de Linguagens Formais. [Abrir demo](https://jonasssgabriel.github.io/ConjuntosRegularesSystem/)

**[PDV Web](https://github.com/jonasssgabriel/pdv-web)**
Ponto de venda que roda inteiro no navegador, com impressão térmica em papel de 80 mm (Epson TM-T20) e dados salvos no LocalStorage. [Abrir demo](https://jonasssgabriel.github.io/pdv-web/)

**[Aplicação em três camadas com Docker](https://github.com/jonasssgabriel/aplicacao-tres-camadas-docker)**
Frontend em Nginx, API interna e Redis atrás de proxy reverso, com rede isolada: só o frontend fica exposto.

**[Chat TCP multiusuário](https://github.com/jonasssgabriel/chat-tcp-multiusuario)**
Cliente e servidor em Java com sockets, pool de threads e protocolo de mensagens em JSON, com interface em Swing.

**[Simulador de tráfego](https://github.com/jonasssgabriel/trafic-control)**
Simulador em PHP 8.3 que roda no terminal, com semáforos, motoristas de comportamento probabilístico e detecção de colisão.

**[Sistema de tarefas](https://github.com/jonasssgabriel/MongoDB-Jonas-Lucas)**
Python com MongoDB Atlas: CRUD completo, busca por status e tag e comentários.

Os demais estão em [Repositórios](https://github.com/jonasssgabriel?tab=repositories).
